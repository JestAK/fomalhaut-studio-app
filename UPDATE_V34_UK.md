# v34

Аналітика → Хто кого озвучував → Додати запис: оберіть «Інший проєкт — лише для статистики» та введіть назву вручну. Назва зберігається лише в записі про озвучену роль, без створення проєкту, серій чи завдань. Старі записи та вибір існуючих проєктів збережено. Такі записи видно при фільтрі «Уся студія».

Оновлення: скопіюйте .env з поточної версії та виконайте sudo bash ops/update.sh.
