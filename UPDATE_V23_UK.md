# v23 — хто що зробив

Вкладка адміна «Аналітика» → «Хто що зробив» (під прогресом серій).

Таблиця: проєкт, сезон і серія, виконавець, напрямок, номер FIX, результат, дата та відкриття завдання. Фільтр проєкту спільний з аналітикою; у розділі є серія, виконавець, напрямок і результат. По 30 записів на сторінку.

У таблиці є завершені завдання й записи, здані на перевірку. Заплановані та нездані не враховуються. Закриті адміном та перенесені завдання позначаються окремо. Для перенесеного прогресу дата виконання невідома; час імпорту не показується як час виконання. Виконавець береться з поточного призначення завдання: цей звіт не відновлює історію перепризначень.

Повний пакет містить усі функції v22. Реліз API: 2026.10.30.23.

Оновлення: виконайте з папки встановленої версії, де є ваш `.env`:

```bash
(
set -e
test -f .env || { echo "Перейдіть у папку поточної програми з .env"; exit 1; }
STUDIO_PREVIOUS_DIR="$PWD"
mkdir -p ~/releases/v23
cd ~/releases/v23
curl -fL --retry 3 https://fomalhaut-studio.fomalhautdub.chatgpt.site/Fomalhaut-Studio-v23.zip -o release.zip
unzip -q release.zip
cd Fomalhaut-Studio
cp "$STUDIO_PREVIOUS_DIR/.env" .env
sudo bash ops/update.sh
)
```

Скрипт зберігає наявні дані й робить резервну копію. Не використовуйте `down -v`. Після оновлення перевідкрийте Mini App або Ctrl+Shift+R у браузері.
