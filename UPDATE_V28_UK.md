# v28
- Успішні завантаження зникають із вікна черги через 8 секунд. Помилки можна скасувати.
- Матеріали серії — спільний розділ із кількома редакторами для кожного типу. Старі призначення переносяться в дозволи; файли та посилання збережені. У задачах, лічильниках і аналітиці роботи матеріали не показуються. Для сумісності прив’язки файлів використовують старі ідентифікатори.
- Часовий пояс у налаштуваннях акаунта: визначення з пристрою при першому вході після оновлення, ручний вибір. Для невідомих поясів — Київ. Дедлайни таблиці, календаря і завдань показуються за поясом виконавця, нові сповіщення — за поясом одержувача. Історичні вже відформатовані повідомлення не переписуються. У формах редагування вказаний пояс введення; UTC у базі зберігається.
- Перший раунд правок більше не враховує сам себе під час обчислення номера: FIX, потім FIX2. Повторне завантаження не змінює раунд. Уже опубліковані назви й старі номери автоматично не змінюються.
- Містить попередні зміни дедлайну зведення: після всіх записів та правок.
API release: 2026.11.02.28. Розпакуйте в нову папку, скопіюйте .env поточної версії, виконайте sudo bash ops/update.sh. Не використовуйте down -v.
