# v27 — скасування невдалого завантаження
У вікні завантажень кнопка «Скасувати» доступна для файлів у черзі та з помилкою. Прибирає картку і виключає файл із подальших спроб. Уже надіслані файли не видаляє. Передавання й серверну обробку ця кнопка не перериває.
Містить зміни v26 для відкладеного дедлайну зведення. Часові пояси виконавців і перетворення матеріалів серії на дозволи ще не включено.
API: 2026.11.01.27. Оновлення: скопіюйте .env поточного релізу, sudo bash ops/update.sh.
