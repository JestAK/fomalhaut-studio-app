# v24 — таблиця виконання по серіях

Аналітика → Хто що зробив: рядки — серії, стовпчики — етапи, у клітинках — виконавці та автоматичні відмітки зі статусів завдань. Кожен актор та кожна ітерація FIX показані окремо. Натискання на виконавця відкриває завдання. Фільтри проєкту, серії, виконавця. Серії відсортовано за номером; на мобільному таблиця прокручується горизонтально з закріпленою колонкою серії.

✓ лише для виконаного; на перевірці, у роботі, очікується та закрито адміном позначені окремо. Відсоток рахується за завданнями всієї серії (включно з запланованими), матеріали та завдання «Інше» виключені. Відмітки не є окремими ручними перемикачами: статус змінюється у самому завданні. Дані й процеси не змінюються. API release: 2026.10.31.24.

Оновлення з каталогу поточної встановленої програми з .env, по одній команді:

```bash
cp .env ~/studio-update.env
mkdir -p ~/releases/v24
cd ~/releases/v24
curl -fL --retry 3 https://fomalhaut-studio.fomalhautdub.chatgpt.site/Fomalhaut-Studio-v24.zip -o release.zip
unzip -oq release.zip
cd Fomalhaut-Studio
cp ~/studio-update.env .env
chmod 600 .env ~/studio-update.env
sudo bash ops/update.sh
curl -fsS https://fomalhaut-team-app.duckdns.org/api/health
```

При помилці зупиніться. update.sh робить резерв і використовує ті ж томи. Не виконуйте down -v. Після успіху перезапустіть Mini App або оновіть браузер Ctrl+Shift+R.
