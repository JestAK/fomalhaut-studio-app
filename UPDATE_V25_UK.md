# v25 — запуск виписування правок
Після успішного надсилання перших записів завдання правкеру створюється також для окремо створених акторських завдань та серій без запису виробничого процесу. Повторні файли не створюють дублікати. Ручні обмеження запуску збережені. Правкер має бути призначений у команді проєкту. Виправлення спрацьовує на наступне надсилання файлів; старі записи автоматично не переобробляються.
API release: 2026.11.01.25.
Оновлення: розпакуйте v25 у нову папку, скопіюйте .env з поточної версії, виконайте sudo bash ops/update.sh.
