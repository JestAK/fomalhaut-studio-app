# v21 — сповіщення, файли до 1 ГіБ і дублікати

1. Дзвіночок стає червоним із червоною крапкою, коли є непрочитані сповіщення поточного користувача. Фонове оновлення значка не перезаписує форми.
2. Кожне непрочитане сповіщення має кнопку «Прочитано». «Усе прочитано» також збережено. Позначки зберігаються на сервері для цього акаунта.
3. Один файл — до 1 ГіБ (1073741824 байти). Ліміт узгоджено в інтерфейсі, Node та Caddy. Читання й хешування потокові; браузер порівнює вибрані файли частинами по 4 МіБ. Час приймання запиту збільшено до 60 хвилин.
4. Повторювані файли в одній вибраній пачці блокуються до надсилання, навіть якщо назви різні. Попередження перелічує дублікати, їх можна прибрати кнопкою біля вибраного файла.
5. Сервер перевіряє оригінальний вміст та отриманий файл перед публікацією. Для записів перевіряються попередні записи й фікси цього актора в тій самій серії та проєкті. Ідентична заміна не створює нової версії і не надсилає файл у Telegram. Для старих файлів без контрольної суми сервер обчислює її за потреби. Це перевірка ідентичності файлів/результату конвертації, не оцінка того, чи актор виконав усі правки.
6. Фільтр «Призначені мені» приховує завершені завдання. Завдання «На перевірці» можна бачити у списку, але вони не входять до значка вкладки: там рахуються тільки власні «Очікується» та «У роботі».

## Встановлення поверх v20

```bash
mkdir -p ~/releases/v21
cd ~/releases/v21
curl -fL --retry 3 https://fomalhaut-studio.fomalhautdub.chatgpt.site/Fomalhaut-Studio-v21.zip -o release.zip
unzip -q release.zip
cd Fomalhaut-Studio
cp ~/releases/v20/Fomalhaut-Studio/.env .env
sudo bash ops/update.sh
curl -fsS https://fomalhaut-team-app.duckdns.org/api/health
```

Очікувана версія: 2026.10.29.21. Якщо .env не знайдено, зупиніться й скопіюйте його з фактично чинного релізу. Скрипт зберігає резерв БД і постійні томи; також перевіряє новий Caddyfile та перестворює контейнер Caddy, щоб новий ліміт завантажень набув чинності. Не використовуйте docker compose down -v. Після встановлення перевідкрийте мініапку, у браузері Ctrl+Shift+R.

Перевірено 36 автоматичних тестів, включно з дублікатами під різними назвами, незміненою заміною WAV/FLAC та правами на позначення сповіщень. У браузері перевірено зникнення крапки після прочитання та лічильник завдань. Фізичний файл 1 ГіБ на ваш AWS під час перевірки не завантажувався.
